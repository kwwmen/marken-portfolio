# VideoPulse — AI-видеообложки для маркетплейсов

Статичный сайт на GitHub Pages.
Сборка: чистый HTML/CSS/JS, без фреймворков.

Структура:
- index.html — главная
- data/ — JSON с работами, отзывами, ценами
- assets/ — статика (шрифты, изображения, видео, скрипты)
